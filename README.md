# Advanced Generative AI with RAGs and Langchain

## A PROGRAM DESIGNED TO PREPARE YOU FOR THE FUTURE OF TECH

E&ICT, IIT Guwahati's comprehensive **Advanced Generative AI with RAGs and Langchain** course is tailored for individuals seeking to stay competitive in the evolving job market and unlock new opportunities for professional growth.

This hands-on program includes a curriculum that is carefully curated in consultation with the industry. The expert-led program helps you gain hands-on experience with cutting-edge tools and techniques, and enhance your career prospects in this rapidly expanding field.

---

## Course Details

### Learning Path

| Phase | Duration | Topics |
|-------|----------|--------|
| **Orientation** | Week 1 | Program Introduction & Setup |
| **Python Advanced** | Weeks 2-5 | Advanced Python Programming Concepts |
| **Exploratory Data Analysis (EDA)** | Week 6 | Data Exploration & Visualization Techniques |
| **Deep Learning and NLP** | Weeks 7-8 | Deep Learning Fundamentals & Natural Language Processing |
| **Foundational Language Models** | Weeks 9-12 | LLM Basics & Architecture |
| **Mini Capstone Project** | Week 13 | Hands-on Application Project |
| **Retrieval-Augmented Generation (RAGs)** | Weeks 14-18 | RAG Systems & Implementation |
| **Vision and Deployment** | Weeks 19-23 | Computer Vision & Model Deployment |
| **Agents** | Weeks 24-25 | AI Agents & Advanced Applications |
| **Capstone Project** | Week 26 | Final Comprehensive Project |

### Final Phase

🎓 **2-DAY GRADUATION AND CAMPUS IMMERSION AT IIT GUWAHATI CAMPUS**
